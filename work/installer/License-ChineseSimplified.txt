第三方组件

  安装目录里包含完整的 .NET 8 运行时与 WPF（MIT 许可），这样你的电脑不需要
  预装 .NET 就能运行 Ceasy。安装程序本身由 Inno Setup 6 编译（Inno Setup
  License），向导的简体中文界面来自社区翻译项目（MIT 许可）。

  这些组件的完整版权与许可正文，安装完成后位于：

      <安装目录>\THIRD-PARTY-NOTICES.md

关于 Codex

  Ceasy 观察 OpenAI Codex Desktop 的任务状态，并且只在你明确授权后代你操作它。
  它不包含也不修改 Codex 的安装包、状态数据库、会话记录或任务内容。

  Ceasy 与 OpenAI 无隶属关系，也未获其背书。

代码签名

  这个安装包没有做代码签名，所以 Windows 首次运行时会显示「未知发布者」警告。
  如需在安装前核对文件完整性，请用发布页附带的 SHA256SUMS.txt 校验。
