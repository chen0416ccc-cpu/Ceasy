About Codex

  Ceasy observes task state in OpenAI Codex Desktop and acts on it only after
  you explicitly authorize it. It does not contain or modify the Codex
  package, its state databases, its session records, or task content.

  Ceasy is not affiliated with or endorsed by OpenAI.

Code signing

  This installer is not code signed, so Windows shows an "unknown publisher"
  warning the first time it runs. To verify the download before installing,
  check it against the SHA256SUMS.txt file published alongside it.
